Tentang Alur Kerja

Kolaborasi Tanpa Saling Menimpa Kode

Projek kecil-kecilan komunitas SIKOKI ini dirancang sebagai simulasi kerja tim nyata di GitHub untuk dua orang pengembang. Alih-alih bekerja langsung di branch utama secara bersamaan, setiap anggota memiliki tanggung jawab komponen yang terisolasi sehingga proses pengembangan berjalan paralel, terstruktur, dan mudah dilacak.

PIC Navbar berfokus pada bagian navigasi atas, menu responsif, dan interaksi tombol mobile melalui branch feat/navbar. Sementara itu, PIC Home bertanggung jawab atas halaman utama, tampilan hero dengan ilustrasi live, bagian tentang, serta penyusunan kartu fitur melalui branch feat/home.

Setelah masing-masing fitur selesai dikerjakan dan diuji pada layar desktop maupun mobile, perubahan dikirim melalui Pull Request menuju branch main. Maintainer akan memeriksa kerapian kode, memastikan tidak ada error di console browser, serta memverifikasi bebas konflik sebelum melakukan merge akhir.

Tahap 1

Sinkronisasi & Branching

Tarik pembaruan terbaru dari main lalu buat branch fitur sesuai peran agar riwayat commit tetap bersih.

Tahap 2

Pengembangan Terisolasi

Edit hanya file dan blok HTML yang menjadi area tugas masing-masing guna menghindari tabrakan baris kode.

Tahap 3

Pull Request & Review

Ajukan PR dengan deskripsi jelas menggunakan template yang tersedia agar proses review dan merge berjalan mulus.
