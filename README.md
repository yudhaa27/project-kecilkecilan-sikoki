# project-kecilkecilan-sikoki

Projek kecil-kecilan tugas komunitas **SIKOKI** untuk membangun tampilan halaman Home sederhana (Navbar + Home) dengan kolaborasi tim **2 orang** di GitHub.

## Struktur Folder

```text
project-kecilkecilan-sikoki/
├── .github/
│   └── PULL_REQUEST_TEMPLATE.md
├── css/
│   ├── base.css        # Reset CSS & variabel tema global
│   ├── navbar.css      # Styling komponen Navbar (PIC Navbar)
│   └── home.css        # Styling tampilan Home (PIC Home)
├── js/
│   └── navbar.js       # Toggle menu mobile Navbar (PIC Navbar)
├── index.html          # Halaman utama
├── CONTRIBUTING.md     # Panduan branching & Pull Request
└── README.md
```

## Cara Menjalankan

Buka file `index.html` langsung di browser, atau jalankan menggunakan ekstensi **Live Server** di VS Code.

## Alur Kolaborasi

Lihat panduan lengkap pembagian tugas, pembuatan branch (`feat/navbar` dan `feat/home`), serta proses Pull Request di [CONTRIBUTING.md](CONTRIBUTING.md).
